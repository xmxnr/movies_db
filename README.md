# API de Películas 🎬

## Descripción

Esta API permite acceder a información detallada sobre películas, incluyendo título, género, director, reparto, y más. Además, permite realizar búsquedas, gestionar una colección de películas favoritas y obtener las más populares. Está construida usando

**Sequelize**
para la gestión de la base de datos y la documentación de la API se realiza a través de **Postman**.
